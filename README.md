## Run the notebook
1. Keep the notebook and CSV in the same folder.
2. Install dependencies if needed: `pip install pandas scikit-learn jupyter`
3. Open the notebook in Jupyter or VS Code and run cells from top to bottom.

## Important
The data shown in the screenshots contains only 12 rows. The documents explicitly flag unknown provenance/permissions, unknown churn definition, and the very small sample. This is a classroom baseline only, not a production-ready model. Before sharing a public project link, do not include any real private customer information.
